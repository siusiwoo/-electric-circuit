# 회로 공작소 (Circuit Lab 3D)

격자 위에 건전지·전선·전구를 놓아 **실제로 전류가 흐르는 회로**를 만드는 3D 퍼즐 게임입니다.
전압과 전류를 흉내내지 않고 **노드 해석법(Modified Nodal Analysis)** 으로 매번 실제로 계산하기 때문에,
잘못 연결하면 전구가 정말로 타버리고 합선을 하면 건전지가 망가집니다.

## 실행 방법

`start.bat` 을 두 번 누르면 작은 웹서버가 켜지고 브라우저가 자동으로 열립니다.
(끝낼 때는 검은 창에서 `Ctrl + C`)

직접 실행하려면 이 폴더에서:

```
python -m http.server 8765
```

그리고 브라우저에서 `http://localhost:8765` 로 들어갑니다.

> `index.html` 을 그냥 두 번 눌러 열면 화면이 비어 있습니다.
> 여러 개의 자바스크립트 모듈을 쓰기 때문에 브라우저 보안 정책상 서버로 열어야 합니다.

## 깃허브에 올린 뒤 실행하는 방법

### 1. GitHub Pages — 설치 없이 주소로 바로 실행 (권장)

이 게임은 서버 프로그램이 없는 순수 정적 파일이라, 깃허브가 그대로 웹사이트로 띄워 줍니다.

1. 저장소 페이지에서 **Settings → Pages** 로 들어갑니다.
2. **Source** 를 `Deploy from a branch`, **Branch** 를 `main` / `/ (root)` 로 고르고 Save.
3. 1~2분 뒤 아래 주소로 접속하면 바로 플레이됩니다.

```
https://<내-깃허브-아이디>.github.io/<저장소-이름>/
```

이 주소는 누구에게나 보내도 바로 열립니다. 파일을 내려받거나 `start.bat` 을 쓸 필요가 없습니다.

### 2. 내려받아서 실행

저장소에서 **Code → Download ZIP** 으로 받아 압축을 풀고 `start.bat` 을 두 번 누릅니다.
(이 PC처럼 git 이 설치돼 있지 않아도 됩니다.)

### 올릴 때 빠뜨리면 안 되는 것

`lib/` 폴더 안의 `three.module.js` 와 `OrbitControls.js` 는 3D를 그리는 라이브러리라
**반드시 함께 올려야** 합니다. 이게 없으면 화면이 검게 나옵니다.
반대로 `node_modules/` 는 올리지 않아도 됩니다 (`.gitignore` 에 넣어 뒀습니다).

## 계산 방식 간단 설명

1. 격자의 접점마다 전압을 미지수로 둡니다.
2. 저항은 옴의 법칙(`I = V/R`)을, 건전지는 "두 단자의 전압 차 = 전압"을 식으로 세웁니다.
   - 건전지는 `이상적인 전압원 + 내부저항 0.4Ω` 으로 쪼갭니다. 그래서 합선해도 전류가 무한이 되지 않고 약 7A 가 됩니다.
   - LED 는 방향에 따라 통하거나 막히므로, 상태가 안정될 때까지 몇 번 다시 계산합니다.
3. 세운 연립방정식을 가우스 소거법으로 풉니다.
4. 구한 전압으로 부품마다 전류 `I`, 전력 `P = I²R` 을 구하고,
   전구 밝기(`P / 0.75W`)와 모터 회전, 과열 여부를 판정합니다.

## 자동 점검

```
npm test
```

회로 계산이 물리적으로 맞는지(옴의 법칙, 직렬 전압 분배, 합선 감지 등)와
모든 스테이지가 실제로 풀리는지, 그리고 **틀린 답은 통과되지 않는지**까지 확인합니다.

브라우저 화면까지 확인하려면 (선택):

```
npm i -D playwright && npx playwright install chromium
npm run shot
```

`tools/shots/` 폴더에 단계별 화면이 저장되고 콘솔 오류가 있으면 알려줍니다.
